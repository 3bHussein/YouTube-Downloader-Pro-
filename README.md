## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎥 **Video Download** | Download MP4 videos (360p to 4K) |
| 🎵 **Audio Extraction** | Extract MP3 audio (64kbps to 320kbps) |
| 📊 **Real Progress** | Percentage, speed, ETA, and file size |
| 🔍 **Video Info** | Get quality and size before downloading |
| 🎨 **Modern UI** | Dark theme with smooth animations |
| 📜 **Scrollable** | Mouse wheel support for all options |
| 💾 **Custom Save** | Choose any download location |
| 🚀 **Standalone** | Single EXE, no Python needed |
| 🔒 **Free** | No registration, no watermarks |

```bash

# Install dependencies
